# Three-Way Merge with Edit-Wins Conflict Resolution

Cloud synchronization uses a three-way merge (`threeWayMergeUnifiedData`) comparing the local Unified Backup, the remote Google Drive Unified Backup, and the last synced Base Snapshot (`last_sync_base`). Deletions on one device propagate only when the counterparty copy is unmodified relative to the Base Snapshot; if one device deletes a Collection Item or Search Engine while another modifies it, the modification wins ("Edit Beats Deletion") to prevent accidental data loss. When no Base Snapshot exists (such as on initial link or after state reset), synchronization falls back to a two-way union merge (`twoWayMergeUnifiedData`) that preserves Collection Items, Tags, and Search Engines from both sides and resolves timestamp ties in favor of the newer entry.
